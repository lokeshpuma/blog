# Blog Platform ✍️✨

A modern and user-friendly **blogging platform** that allows users to create, publish, browse, and manage blog posts with ease.  
Designed with a clean UI, real-time insights, and a smooth writing experience.

---

## 🚀 Features

- 📝 Create and publish blog posts
- 🔥 View currently trending blogs
- 📊 Real-time statistics (posts, words, average length)
- 🔍 Search blogs by title or keyword
- 🗂 Filter blogs (All posts, Quick reads, Deep dives)
- 👤 User-based author display
- 🎨 Clean, modern, and responsive UI

---

## 🖥️ Dashboard Overview

- **Creator Studio** for writing and managing blogs
- **Trending Section** highlighting popular posts
- **Stats Cards** showing:
  - Total posts
  - Words published
  - Average blog length
- **All Blogs Section** with search and filters
